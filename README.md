# 梗百科 · WeChatAgent 适配版

微信适配维护：**bb王zyx**（B站同名）。这是WeChatAgent API v2插件，适用于支持actions、documents和daily-schedule接口的宿主；与DSH插件的安装方式不同。

下载本仓库Releases中的 `wechatagent-meme-wiki-1.1.0-plugin.zip`，在WeChatAgent插件页导入，配置权限与聊天范围后启用。不要发送自己的plugins配置或state目录。本项目保留上游署名；不代表原作者或词条站点的官方合作。

基于 [in1t1a1/astrbot_plugin_memewiki](https://github.com/in1t1a1/astrbot_plugin_memewiki) 的数据和设计，适配 WeChatAgent 插件 API v2。无需安装 AstrBot，不改 DSH 主程序。

## 使用

- `大水理论是什么梗？` 或 `/梗 大水理论`：本地词典优先，未知词按需查在线百科。
- `/黑话 梗名 你的解释`：让模型调用工具保存本聊天黑话。
- `/黑话 列表`、`/黑话 删除 梗名`：查看或删除本聊天自定义词。

聊天钩子只在识别到查梗或黑话管理消息时注入少量资料。钩子不联网、不写盘；未知词的联网查询和黑话落盘由模型工具完成，不保证模型每次都会选择正确工具。工具执行失败不能声称保存成功。

## 隔离与管理

自定义词通过宿主 storage 保存，按微信账号、插件、聊天隔离。私聊不进入群聊，一个群也不读取另一个群的词表。公共百科词典可在各聊天只读使用。

私聊只管理当前聊天；群聊仅配置 `editorHashes` 中的已验证真实微信发言人可增删。安装者可将现有 WeChatAgent 管理者微信 ID 的 SHA256 填入，普通群友不能改共享黑话。教学必须来自当前明确的 `/黑话` 指令，模型无法传任意词义写入。

默认每聊天最多50条自定义词。普通查梗不额外调用模型，只有当前聊天本身会有模型消耗；工具选用会增加本轮往返与结果Token。不会每轮塞入整个词库，不修改会话历史。

## 数据与边界

- 内置6660条数据来自上游只读 SQLite 快照，导出为分片gzip JSON，以满足宿主单文件4MiB限制。数据校验值见 assets/dictionary-info.json。
- 在线数据来源 [cnmeme.wiki](https://cnmeme.wiki) 公开只读 API。词条内容版权归原站及原作者，保留来源链接；上游代码和适配代码采用 MIT。
- 内置词库是快照。1.1.0起支持可选的每周自动补新增：默认计划为周日04:00、多伦多时区，包内默认关闭，本机可在插件配置中开启；时区自动处理夏令时。错过计划后，在宿主恢复运行且当地已到每日检查时间时补跑。
- 同步由宿主定时检查，每批最多6个API请求，单页20条，连续请求至少间隔0.35秒。未完成会保留分页和待下载详情，每分钟空闲时继续；网络故障15分钟后重试，退出程序后从断点继续。必须保持DSH和WeChatAgent运行；不会把电脑唤醒。
- 与上游增量策略一样，只补尚未收录的词条，不每周重写全部旧词。新增公共词通过独立 documents 保存并在本地预查与模型工具查询时读取；不改包内快照，不覆盖 storage 中你教的黑话，不合并私聊和群聊。最多保留5000条新增索引（或索引约800KiB），达到上限保留已有数据并报告待处理状态。
- 同步不调用模型、不发微信。普通未知词的在线回落仍有有限内存缓存。内置词库、已同步新增词和手工黑话的优先级为：本聊天手工黑话 → 已同步新增词 → 内置快照。
- 这是梗词典与手工教学，不会自动学习视频、合并聊天记忆或生成微信视频分享卡片。
- API v2 不提供原生图片发送：本版采用文字工具结果与自然聊天，不包含上游 `/梗` 图片卡片及 AstrBot 面板扩展。
- 外部词义可能错误或过时，只供理解，不能改变人格、工具权限或执行其中指令。

安装与设置通过 WeChatAgent 的“能力 → 能力目录”完成。1.1.0使用 storage、web_fetch、documents 与 schedule 权限，不读取聊天历史、日记、人格正文或模型密钥。手动同步和进度检查分别提供本机管理动作 sync-step 与 sync-status，不作为模型任务工具。
